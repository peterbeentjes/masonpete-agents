## Why this exists

Agentic AI stops where it starts. Someone builds a Copilot agent, it answers questions, and then? Nobody watches whether it sees the right data, does something dangerous, or still works when Microsoft changes an API next month.

This swarm solves that: Chief of Staff keeps the overview, Solution Architect checks the design, Compliance Agent collects the evidence. The difference between a demo and a system you can trust with client data.

## The three templates

- **Chief of Staff** — daily briefing from inbox, Teams, GitHub and DevOps. Escalates only what blocks revenue, compliance or a deadline. Never sends, spends or merges without approval.
- **Solution Architect** — design review against Microsoft Learn and Well-Architected. Concrete entity and field placement. Never touches production.
- **Compliance Agent** — NIS2 and ISO 27001 evidence collection and gap analysis for Power Platform. Drafts remediation, never executes it.

## Install (step by step)

Each recipient does this once per template. Takes about twenty minutes.

1. **Get a Grok Bot account** at grok.com/bot (or x.ai/bot). Free tier works for testing.
2. **Open the template link** from this repo or the Grok Bot marketplace. The bot charter loads with its instructions, memories, skills and routines.
3. **Review the charter.** Read the description and the anti-job line. If it says never touch production, believe it.
4. **Strip secrets.** In the template draft, delete anything listed under memories_to_strip: client names, API keys, internal URLs, tenant IDs. Secrets are not removed automatically.
5. **Connect read-only sources only.** Outlook read, Teams read, GitHub read, Azure DevOps read. No write access. No browser sessions. No deploy rights.
6. **Name your own paths.** Tell the bot your inbox name, repo paths, channel names. It will not guess.
7. **Run one dry run.** Ask for a morning briefing or a gap analysis manually before enabling any routine. Check that output matches what you expect.
8. **Enable the routine** (Chief of Staff: weekday 07:30; Compliance Agent: Monday 09:00). Solution Architect has no schedule — it responds when you feed it a design.
9. **Add your escalation contacts** as a memory after install. Who gets pinged when something blocks revenue.
10. **Keep remediation drafts** in a folder the bot cannot write to production. Separation is the product.

## Why not build it yourself

Building a bot is an afternoon. Running a governed fleet is an operation: per-client isolation, approval gates, Microsoft-best-practices review, continuous updates. Most mid-market firms have no one whose job that is — same reason they outsource hosting and security monitoring.

The product is nearly free. The operation is the market.
